# ADR 0001：MVP 采用 FastAPI 单体架构

## 状态

已接受，适用于 MVP 脚手架阶段。

## 背景

产品需要尽快验证营养基线、菜谱、周计划和采购清单这条主流程。Vue/React、独立 FastAPI、Supabase 三套运行时同时启动会增加部署、认证和调试成本。

## 决策

第一阶段使用一个 FastAPI 应用：

* 提供 `/api/v1` API。
* 托管 `frontend/` 下的静态移动端页面。
* 先保持数据库适配层可替换，不在脚手架阶段锁定最终表结构。
* 营养计算在服务端完成，避免前端计算规则分叉。

## 后果

优点是本地启动简单、依赖少、适合快速验证；缺点是前端工程能力和离线能力有限。产品验证通过后，可以把静态页面迁移到 Vue/React，并将持久化切换到 Supabase。
