# ADR 0002：数据库结构保持待确认

## 状态

讨论中，暂不作为最终迁移方案执行。

## 当前候选实体

`profiles`、`ingredients`、`recipes`、`recipe_ingredients`、`meal_plans`、`meal_plan_items`。

## 待确认问题

1. `recipe.servings` 是否表示整锅菜的可分装份数。
2. 产品第一版是规划午餐，还是规划全天饮食。
3. 营养目标是否需要历史版本；暂定周计划保存创建时的目标快照。
4. 食材营养数据是否统一为生重，以及是否需要记录来源和版本。
5. 采购清单是否只作为实时派生结果，不单独持久化。
6. 菜谱总营养是实时聚合，还是允许保存服务端维护的缓存字段。

## 暂定原则

在上述问题确认前，不继续扩展 `supabase/schema.sql`，避免把未经讨论的业务假设固化为迁移脚本。
