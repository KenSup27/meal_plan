## 联调发现并修复

首次真实浏览器运行在基线保存处发现 422：Pydantic 直接比较 Decimal 枚举与 JSON 浮点数，
活动系数 1.2/1.55 不被接受，而原测试只覆盖恰好可精确比较的 1.375。
现先按字符串转换 Decimal，再做枚举校验；三个合法选项和非法输入均补齐 API 回归。
浏览器测试等待保存请求成功及已保存摘要出现，避免把空状态中的“每日目标”误当保存成功。

测试清理还发现云端完整性函数落后于当前 main：旧函数在父菜谱已被删除时仍要求子食材存在，
且缺少计划改周约束。独立 integrity.sql 同步现有 schema 中的三个函数和改周触发器，
不扩展业务表、不放宽 RLS、不更改用户数据。升级后真实云端约束补测及精确清理成功。
清理先删除专用账号计划，再删除账号，避开菜谱引用的 RESTRICT 外键删除顺序。
